# college-dz-bot

Телеграм-бот с домашкой и расписанием для группы. Данные хранятся локально в JSON, а медиафайлы подгружаются через file_id без сохранения на диск.

### Что есть
* Расписание пар и домашка по предметам
* Фильтр по подгруппам (1 / 2)
* Личные отметки о выполнении заданий
* Прикрепление фото, видео, документов к предмету
* Уведомления при обновлении ДЗ и панель модератора
